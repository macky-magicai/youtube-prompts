# youtube-prompts

YouTube「マッキーのちょこっと便利なAI」の動画で紹介したプロンプト集です。

## PDF分割ツール

紹介動画：[【AI×プロンプト1発】PDF分割ツールを無料で作れるか？チャレンジしてみた](https://youtu.be/ft5xshgd92c)

| ファイル | 中身 |
|:---|:---|
| `PDF分割ツール_生成プロンプト_20260214.md` | AIに貼り付けると、PDF分割ツールを作ってくれるプロンプト |
| `ai_studio_code.html` | プロンプトから作った完成品。開くときにインターネットが必要です |
| `20261003_1125_PDF分割ツール_ネット不要版.html` | 完成品のネット不要版。インターネットにつながっていないパソコンでも動きます |

### 使い方

1. 使いたいファイルをクリックして開く
2. 右上の「↓」（Download raw file）を押して保存する（GitHub のアカウントは要りません）
3. 保存したファイルをダブルクリックすると、ブラウザで開いて使えます

- ブラウザは Microsoft Edge か Google Chrome（新しいもの）で開いてください
- どちらの版も、PDFの中身が外部に送られることはありません。処理は手元のパソコンの中だけで行われます
- 完成品（`ai_studio_code.html`）は、PDFを扱う部品を開くたびにインターネットから読み込みます。ネット不要版は、その部品をファイルの中に入れてあります（約2MB）。使っている部品とライセンスは、ファイルの末尾に書いてあります
